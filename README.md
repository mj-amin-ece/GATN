# GATN

Graph Attention Network (GATN) project exploring dataset analysis, model evaluation, and integration with Graph Neural Networks (GNNs).

## 📘 Project Overview

Test **Graph Attention Networks (GATs)** on a new dataset for **multi-label classification** to identify **eye diseases** based on medical images.  
The goal is to explore the performance of GAT models compared to traditional CNN-based models such as EfficientNet.
---

## 🚀 Project Steps

### **Step 1: Dataset Exploration**
- Get familiar with the dataset.
- Perform initial data analysis and preprocessing.
- Understand data structure, labels, and key features.

### **Step 2: Baseline Model with EfficientNet**
- Test the dataset using **EfficientNet** as a baseline model.
- Evaluate performance metrics (accuracy, loss, F1-score, etc.).
- Save and document the results for comparison.

### **Step 3: Integrate Graph Neural Network (GNN)**
- Read and understand the related **GAT (Graph Attention Network)** paper.
- Implement a GNN model to process data graphically.
- Compare results with EfficientNet baseline.
- Visualize results and model performance using graphs.

---

## 📊 Planned Outputs
- Dataset insights and visualizations.
- EfficientNet baseline performance metrics.
- GAT model implementation and comparison.
- Graph-based performance visualizations.
